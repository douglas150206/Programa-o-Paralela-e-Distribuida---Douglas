# Internet e Transformações do Final do Século XX: Redes Sociais

Apresentação em grupo de História da Ciência e Tecnologia (JCRHCTC, SUP.18201), ADS, IFSP Jacareí.

| Arquivo | O que é |
| --- | --- |
| [`slides.pdf`](slides.pdf) | Os 42 slides em PDF. Abre direto aqui no GitHub. |
| [`slides.html`](slides.html) | Os slides para apresentar no navegador, com o roteiro de fala de cada slide. |
| [`index.html`](index.html) | O site do trabalho. |

O GitHub mostra só o código dos arquivos `.html`. Para ver, baixe o arquivo e abra no navegador. Deixe os dois na mesma pasta para o botão "Abrir os slides" do site funcionar.

No `slides.html`:

- <kbd>←</kbd> e <kbd>→</kbd> passam os slides (clicar ou deslizar o dedo também funciona).
- <kbd>F</kbd> deixa em tela cheia.
- <kbd>N</kbd> mostra o roteiro de fala embaixo do slide.
- <kbd>P</kbd> abre uma janela só com o roteiro, para deixar no notebook enquanto o projetor mostra os slides.
